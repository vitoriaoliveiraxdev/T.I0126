# 🎮 Projeto LAN House – E-Game

## 📌 Sobre o projeto
Montagem e configuração de uma LAN House para a realização de um campeonato de jogos eletrônicos.

## 🎯 Objetivo
Preparar uma estrutura de computadores interligados em rede para a realização de partidas do jogo Urban Terror.

## 💻 Estrutura
- 01 Servidor
- 08 PCs para jogadores
- 03 PC para Backup
- 01 PC para narrador

## 🛠️ Softwares e tecnologias
- Sistema operacional: Windows 11 Professional
- Gerenciamento: Timer Café
- Jogo: Urban Terror
- Infraestrutura: Rede local (LAN)
